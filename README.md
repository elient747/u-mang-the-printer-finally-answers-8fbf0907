One original line, 1 to 240 characters: the office printer's comeback to the jams, the error codes and the thumps — weary, literal, faintly passive-aggressive.

## Run it

```sh
python3 -P -s main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
